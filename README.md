# ATLAS: облака, ИИ и риски банка

Аналитический портал для CIO банка: рынок облаков, технологический радар, реестр рисков, план на 90 дней, калькулятор FinOps и дашборд облачных расходов.

Сайт статический: откройте `index.html` в браузере или опубликуйте репозиторий через GitHub Pages.

## Загрузка своих данных

В разделе **«Данные»** можно перетащить файлы `.xlsx`, `.xls` или `.csv`. Дашборды пересчитываются сразу. Данные хранятся только в браузере (localStorage) и никуда не отправляются. Кнопка «Вернуть демо» сбрасывает их.

* **Шаблон Excel** — книга с листом на каждый набор данных и листом «Справка».
* **Текущие данные** — выгрузка того, что сейчас показано на дашбордах.
* Примеры CSV лежат в папке [`templates/`](templates).

Тип таблицы определяется по имени листа или файла, а если не получилось — по заголовкам. Порядок колонок не важен, названия распознаются по началу слова на русском или английском. Числа можно писать с запятой (`1 234,5`), CSV из русского Excel (разделитель `;`, кодировка Windows-1251) читается корректно. Строки с ошибками пропускаются, а их номера показываются в отчёте.

### Модель таблиц

`*` — обязательная колонка.

**Облачные расходы** (`templates/costs.csv`) → дашборд «Расходы», KPI, калькулятор FinOps

| Колонка | Тип | Пример |
|---|---|---|
| Месяц * | `2026-01`, `01.2026`, `янв 2026` или дата Excel | 2026-01 |
| Сервис * | текст | Мобильный банк |
| Категория * | текст | Вычисления |
| План, млн ₽ | число | 2,4 |
| Факт, млн ₽ * | число | 2,51 |
| Транзакции, млн | число | 260 |

**Рынок облаков** (`templates/market.csv`) → раздел «Рынок»

| Колонка | Тип | Пример |
|---|---|---|
| Год * | целое | 2024 |
| Поставщик * | текст | Amazon |
| Выручка, млн USD * | число | 64804,9 |
| Доля, % | число; если пусто, считается из выручки | 37,7 |

**Облака в бизнесе** (`templates/adoption.csv`): Срез *, Название *, Доля, % *

**Технологический радар** (`templates/tech.csv`): Технология *, Полное название, Статус * (Внедрять / Пилотировать / Наблюдать), Сектор * (Данные и ИИ / Облако / Операции / Доверие), Индекс 0–100 *, Горизонт, Метрика пилота, Описание, Следующий шаг

**Реестр рисков** (`templates/risks.csv`): Риск *, Вероятность 1–5 *, Влияние 1–5 *, Владелец, Мера, Причина, Статус (В работе / Выполнено)

### Что считается на дашборде расходов

* Факт за период и отклонение от плана (по строкам, где указан план).
* Прогноз на год: среднее за три последних месяца × 12.
* Самая быстрорастущая категория: последние 3 месяца к первым 3.
* Стоимость 1000 транзакций: факт ÷ объём операций по сервисам, где объём указан.

## Структура

```
index.html          разметка
assets/style.css    минималистичная тема (светлая и тёмная)
assets/fonts.css    шрифт Onest (встроен)
assets/data.js      справочные тексты, источники, демо-данные
assets/import.js    модель таблиц, разбор CSV/Excel
assets/app.js       дашборды и интерфейс
templates/*.csv     примеры таблиц
```

Библиотеки с CDN: Chart.js 4.4.1 (графики), SheetJS 0.18.5 (Excel). Шрифт Onest распространяется по SIL Open Font License 1.1.
